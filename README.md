# Physics Simulations in Python

This repository contains a collection of small physics and computational simulations created using Python. 
The goal of these projects was to explore how mathematical models and simple rules can be used to simulate real-world systems.

## Simulations Included

### 1. Projectile Motion Simulation
A 2D simulation showing the trajectory of a projectile launched at an angle under constant gravity.  
The simulation calculates position at small time intervals to visualize the parabolic path.

Concepts:
- Equations of motion
- Constant acceleration
- Numerical time stepping

### 2. Bouncing Ball Simulation
A simulation of balls bouncing under gravity with different energy loss values.  
Each bounce loses some energy, demonstrating how motion gradually decreases over time.

Concepts:
- Collisions
- Energy loss (coefficient of restitution)
- Motion visualization

### 3. Conway's Game of Life
A cellular automaton where complex patterns emerge from simple rules applied repeatedly on a grid.

Concepts:
- Emergent behavior
- Cellular automata
- Rule-based simulation

### 4. Lorenz Attractor
A chaotic system demonstrating the butterfly effect, where very small changes in initial conditions lead to drastically different outcomes.

Concepts:
- Chaos theory
- Nonlinear dynamical systems
- Sensitivity to initial conditions

### 5. Particle Motion Simulation
A simulation of particles moving and bouncing inside a boundary, creating dynamic patterns based on simple movement rules.

Concepts:
- Random motion
- Particle interactions
- Visual simulation

## Tools Used
- Python
- NumPy
- Matplotlib
